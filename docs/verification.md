## Границы проверки

Docker Desktop установлен. Конфигурация Compose проходит `docker compose --env-file .env.example config --quiet`, задано стабильное имя проекта `mai-team`. Попытка запуска Desktop через CLI выполнена, но движок не отвечает: канал `dockerDesktopLinuxEngine` отсутствует. Поэтому контейнерная сборка nginx/Compose и контейнерные тесты пока не проверены. Проверены сборка Vite, Python API, настоящие SQL-миграции и база вне Docker. Полного нагрузочного теста и проверки во всех браузерах не было. Это локальная версия для просмотра и дальнейших правок, не публичное развёртывание.

Секреты, зависимости и переносимый PostgreSQL находятся только в игнорируемых каталогах проекта. Push и публикация не выполнялись.
