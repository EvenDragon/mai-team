# Поведение первой версии

Цель: студент находит проект или создаёт свой, получает решение по отклику и связывается с командой.

## Доступные сценарии

1. Каталог без регистрации: поиск, направление, формат, навык, свободные места, пагинация.
2. Регистрация, вход/выход, редактирование профиля и просмотр профилей авторизованными участниками.
3. Создание проекта с ролями и контактами команды, отправка на модерацию.
4. Проверка публикации, возврат с объяснением, повторная отправка после редактирования.
5. Отклик, принятие/отклонение автором, отзыв ожидающего отклика.
6. Мои команды, выход из команды, удаление участника автором, открытие/закрытие набора.
7. Жалоба на проект/профиль, рассмотрение, замечание, скрытие проекта, блокировка/разблокировка, история.

Статус публикации отделён от набора. Команда сохраняет доступ после закрытия набора и повторной проверки. Контакт доступен автору, модератору и принятым участникам. Новая жалоба сама не скрывает контент.

Вне первой версии: каталог людей и приглашения, чат, задачи команды, рейтинги, подтверждение вузовской почты и восстановление пароля. Непрерывное сохранение опубликованной редакции при правках также отложено.
