# PostgreSQL

`migrations/001_initial.sql` — исходная схема. `002_teams_and_moderation.sql` добавляет независимый набор, приватный контакт, блокировки, жалобы и историю решений.

Из `backend` запусти `python -m app.migrate`, предварительно задав `DATABASE_URL`. Мигратор записывает контрольные суммы в `schema_migrations`, выполняет новые файлы по очереди и не повторяет применённые. Не редактируй уже применённые миграции — добавляй следующие.

При обновлении старые `closed` становятся `pending` с закрытым набором: невозможно надёжно узнать, были ли они раньше опубликованы. Команды и отклики сохраняются. Такие проекты нужно проверить повторно.

`seeds/001_demo.sql` содержит только вымышленные данные. `python -m app.seed` требует явного `ALLOW_DEMO_SEED=true`. Не загружай демо в реальную пользовательскую базу.

Для настоящих данных сначала делай резервную копию. Откат исходного кода не откатывает схему. Подробности: [FORDEV.md](../FORDEV.md).
